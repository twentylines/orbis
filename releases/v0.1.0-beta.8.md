# Orbis v0.1.0 beta 8

This remains a development preview for isolated homelab testing. It targets the Runtipi v4.10.1 CLI data and application layout.

## Since beta 7

- Added a guarded first adoption command for a self-contained stock Runtipi v4.10.1 installation. It verifies the published Orbis digest, captures a stopped-state snapshot, and can restore the original stock image and data after a failed cutover.
- Added a separate Unix socket host service for reviewed Orbis core updates, with a short-lived plan, job status, and interrupted-transaction recovery. The authenticated browser API requires an operator session and same-origin mutation requests.
- Added an Update Center review panel that shows the target digest and snapshot estimate before installation. It stays unavailable until the host service is connected to a healthy enrolled installation. The fixed dock moves out of the way during review.
