# Orbis v0.1.0 beta 8

This remains a development preview for isolated homelab testing. It targets the Runtipi v4.10.1 CLI data and application layout.

## Since beta 7

- Added a guarded first adoption command for a self-contained stock Runtipi v4.10.1 installation. It verifies the published Orbis digest, captures a stopped-state snapshot, and can restore the original stock image and data after a failed cutover.
- Added a separate Unix socket host service for reviewed Orbis core updates, with a short-lived plan, job status, and interrupted-transaction recovery. The authenticated browser API requires an operator session and same-origin mutation requests.
- Added an Update Center review panel that shows the target digest and snapshot estimate before installation. It stays unavailable until the host service is connected to a healthy enrolled installation. The fixed dock moves out of the way during review.

## Verification before publication

- A synthetic stock CLI installation adopted the published beta 7 arm64 image while keeping its account and inherited Whoami app. An injected failure after Orbis started restored stock v4.10.1 at its captured image ID and verified snapshot. Hades was not touched.
- The Unix socket service reported the enrolled beta 7 core as healthy in the isolated Docker environment and rejected a same-digest plan. Python transaction tests, backend authorization and socket transport tests, type checks, and local production builds passed.
- Chrome fixture checks of the new review panel passed at desktop, phone, and 320px widths with no horizontal overflow or page errors. The dock no longer covers the confirmation controls.
- Repository CI and integration tests gate this release. Runtime validation of this tag's published image and a browser-driven core update are separate steps after publication.

## Current limits

The host service is a test interface and still needs a Linux socket mount, process supervision, and a published-image browser update rehearsal. Managed apps must be stopped, and external app mounts or Docker volumes are outside the current snapshot path. Host operating system package updates, real homelab migration, and multi-server pairing remain open. Do not replace a production Runtipi installation with this preview.
