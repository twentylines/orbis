# Orbis v0.1.0 beta 18

This is a development preview based on Runtipi v4.10.1. Hades has not been changed.

## Desktop and layout

- Removed the exposed page strip above the desktop and increased system-bar and window insets. Removed repeated top-level route titles and slug labels.
- Rebalanced the default home screen around the app launcher, recent operations, warnings, and a combined System status panel. Storage is now inside status.
- Replaced repeated SVG mask IDs in app icons with standard image elements and a bundled fallback. The isolated server's 248 catalogue and installed icons passed a browser decoding audit.

## Docker health and resources

- App launchers and installed app tiles now show actual Docker health. Running apps without healthchecks are labelled explicitly.
- Added shared, bounded Docker telemetry and CPU/memory rankings in System status and Monitor. The expanded view lists containers and their state, health, memory limit, network counters, and disk I/O counters.
- CPU uses Docker's per-core convention. Missing readings and disconnected Docker state remain unavailable.

## Task centre

- Added a persistent lifecycle history with queued, running, completed, failed, interrupted, and unconfirmed outcomes. It remains visible across navigation and reloads.
- Keeps up to 300 records for 30 days, without configuration or raw error payloads. Corrupt storage is preserved and storage failures are shown in the UI.

## Verification

The production bundle, types, backend tests, visual fixtures, real Docker telemetry, and disposable app start/stop task history were checked locally. Saved outcomes survived an isolated core restart. GitHub CI and integration checks gate publication.

## Current limits

Full theme packs, advanced personalisation, multi-server pairing, expanded host telemetry/history, and real-data migration remain incomplete. Docker ranking covers containers rather than all host processes. Task history covers lifecycle commands; host/core update journals remain in Update Center. Production cutover and amd64 runtime remain unverified.
