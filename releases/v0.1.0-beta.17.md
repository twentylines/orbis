# Orbis v0.1.0 beta 17

This remains a development preview based on Runtipi v4.10.1. Hades has not been changed.

## Since beta 16

- Added a visible light/dark switch in the system bar and in Appearance. The choice is saved per account, cached locally, and restored on reload. Older Graphite settings keep their dark appearance.
- Deepened the workspace instruments with recessed live CPU and memory dials, an etched system panel, a layered filesystem marker, and a status-driven operations beacon. Motion respects reduced-motion settings.
- Updated the auth screen and application windows to follow the chosen mode, and refreshed desktop, phone, and narrow-screen screenshots including a dark workspace capture.

## Verification before publication

- The production bundle, TypeScript checks, backend tests, and visual fixture must pass locally. GitHub CI and isolated integration tests gate image publication.

## Current limits

This is an interface preview, not a finished replacement for a live Runtipi server. The full theme system, multi-server pairing, additional host management, real Hades migration, external mounts and named volumes, and amd64 runtime still need implementation or live validation. The Ubuntu host-update helper remains limited to 24.04 and package changes have no automatic rollback.
