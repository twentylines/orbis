# Orbis beta59

## Backup uploads

- Stream uploaded archives to private disk storage instead of keeping the entire file in memory.
- Check archive structure, app configuration and app identity before adding a backup to the list.
- Store uploaded backups with private file permissions. Keep an existing backup when its filename is already in use.
- Clean interrupted transfers and cancel validation when the client disconnects. Retry abandoned temporary-file cleanup on the next upload.
- Keep support for legacy backup filenames and uncompressed tar contents.

App configuration metadata is limited to 1 MiB. This limit does not apply to the app data inside the backup. Allow enough disk space for the incoming archive.

This corrects beta58's upload validation and file-permission issues. See [App backups](https://github.com/twentylines/orbis/blob/main/BACKUPS.md) for storage and recovery requirements.

This is a prerelease. Migration of an existing homelab, external app data and complete device/browser acceptance remain unverified.
