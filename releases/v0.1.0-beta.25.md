# Orbis beta 25

## Layout and recovery

- Replace the oversized page-error box with a compact card, aligned recovery actions, and expandable page/error details. Returning to the workspace resets the route error boundary.
- Use consistent 24px desktop insets across the system bar, Home, full-page tools, search and notifications. Remove the desktop width caps, tighten Appearance columns and keep ultra-wide Settings in a readable focused window.
- Let Home headings/actions, storage and Docker resource rows, app tabs and pin controls reflow when text is enlarged.
- Keep full dock labels, allow horizontal scrolling when needed, and reveal focused items during keyboard navigation.
- Place login attribution inside the themed card and use theme colours for input placeholders, password-reset instructions and empty-state icons.

## App settings

- Preserve stored app settings and backup-retention overrides during app upgrades. An upgrade no longer reapplies an old installation form as a settings edit.
- Generate the new app environment before pulling the updated image. A required-field failure reports a failed update without a version bump or automatic restart.
- Save the selected backup-retention override on a fresh installation, including zero.
