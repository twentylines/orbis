- Add current host temperatures, fan RPM and GPU identity to Monitor. AMDGPU activity and VRAM appear where the Linux driver exposes them; unsupported readings remain unavailable. Valid zero readings, sensor faults, disabled channels, critical thresholds and partial coverage stay explicit.
- Refresh hardware readings every 30 seconds while Monitor is visible. A shared bounded helper worker reads selected kernel attributes without running commands or changing hardware settings. Hidden/minimized views stop their browser polling.
- Preserve a focused Docker details control when live resource rankings reorder. If its row disappears, focus moves to the surviving Usage heading; refresh does not steal focus after the user moves away.
- Keep comfortable disclosure padding, wrapped ordinary fallback copy, full accessible device labels and theme-aware warning text. The top bar, coloured titlebars and dock retain their shared translucent blur without white frame rims.
