# Orbis beta 37

## Custom Home layouts

- Custom widget rows fill the available width while retaining the useful proportions between wide and normal cards.
- The Applications launcher uses its content height instead of forcing an empty gap beneath a short app list.
- The default layout and phone single column retain their existing arrangement. Saved widget order, visibility, widths and app pins are preserved.
- Show-all app scrolling remains bounded when a lower card is enabled. Hiding both lower cards allows the app list to grow normally.

## Database dependency

- Both workspaces use Drizzle ORM 0.45.4, past the quoted-identifier escaping fix. PostgreSQL alias/identifier regression checks retain embedded quotes inside one quoted identifier.
