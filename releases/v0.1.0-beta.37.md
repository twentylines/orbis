# Orbis beta 37

## Custom Home layouts

- Custom widget rows fill the available width while retaining the useful proportions between wide and normal cards.
- The Applications launcher uses its content height instead of forcing an empty gap beneath a short app list.
- The default layout and phone single column retain their existing arrangement. Saved widget order, visibility, widths and app pins are preserved.
- Show-all app scrolling remains bounded when a lower card is enabled. Hiding both lower cards allows the app list to grow normally.

## Database dependency

- Both workspaces use Drizzle ORM 0.45.4, past the quoted-identifier escaping fix. PostgreSQL alias/identifier regression checks retain embedded quotes inside one quoted identifier.

## Verification boundary

The compiled-source layout matrix passes 112 cases across 1440/768/390/320px, both modes, native/doubled text and seven app-count/layout arrangements. Ten keyboard-End scroller cases pass; representative captures received independent visual inspection. The prior source bundle reproduced the unused row width and forced launcher gap, and the final candidate removes both. Frontend build and scoped lint/syntax checks pass. The ORM source patch passes backend tests, types, bundle and main CI/integration.

The published-image driver now rejects custom row gaps and forced independent launcher height. Publication must be followed by a reviewed isolated OTA, snapshot/data comparison and released-image/login checks. This preview does not complete copied real-data migration, physical devices, other browsers, full theme packs or multiple homelabs. Three lower-severity dependency alerts remain tracked in DEPENDENCY-SECURITY.md. Hades is unchanged.
