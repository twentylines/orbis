# Orbis beta69

## Runtipi replacement

- Recognize registered apps launched through external maintenance Compose files. Ownership requires a matching app identity, the installation's real app-data bind and valid local app registration. Installed aliases can differ from catalogue IDs.
- Keep app containers running during the guided replacement. Back up configuration and control services separately from live app data; pause only the controller, database, queue and reverse proxy. Access through the reverse proxy can pause during cutover.
- Preserve newer app writes during rollback, while restoring configuration, authentication cache and control-service data. Reject shared writable metadata and hard links crossing backup boundaries before copying.
- Retain the explicit full-backup option and recovery compatibility with existing full-backup journals. Unknown or conflicting managed-container ownership still blocks replacement with container names, IDs and reasons.

```sh
curl -fsSL https://twentylines.github.io/orbis/install | sudo python3
```
