# Orbis 0.5 beta 1

- New installer with automatic Docker and Compose setup.
- Revamped Settings with search and separate update schedules.
- More compact Store cards and better suggestions.
- Improved task alerts, backups and Updates.
- Private HTTPS setup and simpler cluster pairing.
- Refined focus states and animations.

Runtipi remains at 4.10.1. No data migration is required.
