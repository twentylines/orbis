# Orbis beta61

## Restore recovery

- Recover interrupted restore files without automatically running the restore again when the queue reconnects.
- Prevent duplicate execution of the same restore request, including deliveries whose earlier task history is no longer available.
- Keep completed task outcomes. Leave interrupted restores visible for review before starting a new restore.

This is a prerelease. Migration of an existing homelab, external app data and complete device/browser acceptance remain unverified. See [App backups](https://github.com/twentylines/orbis/blob/main/BACKUPS.md) for storage and recovery requirements.
