# Orbis v0.1.0-beta.30

## Changes

- Long server names use a readable phone heading and wrap at word boundaries.
- Recent operations keep app names compact, with the complete name available to assistive technology and on hover.
- Home links have consistent row spacing and full-size arrows.
- Search results give long names more room and keep complete words together. Long queries wrap in the no-results message, and the search input grows with text size.
- Timezone and other Select menus keep space from screen edges, preserve selection indicators and scroll within the available viewport.
- Log controls and environment actions reflow with enlarged text. Password and username fields keep visible labels.
- Installer fields, domain suffixes and the Random port action stay within their scrolling dialog.
- The Compose service sidebar adapts to panel width and text size. Section tabs wrap as whole buttons; service, port, volume and environment actions stay separated from their headings. Keyboard focus reveals the complete table action and its focus marker.
- Long IPv6 addresses leave room for the wordmark and controls. Connecting, Reconnecting and the missing-address message stay fully visible. The theme button keeps its icon and stable width when text is enlarged.

The isolated beta29 custom-store rehearsal passed a backed-up v2 to v3 upgrade, preserved settings, data and overrides, generated the new default before starting, and verified both services and private-network DNS.

The inherited Runtipi backend and configurations remain in place. Full production migration acceptance is still in progress; Hades has not been replaced.
