# Orbis v0.1.0 beta 2

This remains a development preview for isolated homelab testing. It is based on Runtipi v4.10.1 and retains its accounts, app catalogue, lifecycle, backups, and data layout.

## Since beta 1

- The Monitor now samples host CPU counters from a read-only `/proc/stat` mount where available. It labels the container fallback when host counters are unavailable.
- A live CSS perspective view shows this server's CPU and memory beside the detailed charts. It reflows on narrow screens and honors reduced motion.
- Migration preflight catches copied CLI installations whose `ROOT_FOLDER_HOST` still points to the original location. The release planner distinguishes the configured Compose image from the image actually running.
- The initial editable server display name remains **Hades**, as requested; **Orbis** is the product name.

## Verification

- The beta 1 published digest booted on a disposable synthetic Runtipi CLI v4.10.1 installation with an inherited account and Whoami app. The browser's Open action launched Whoami at its configured port with HTTP 200.
- The beta 2 source build passed local type checks, targeted tests, and browser checks at desktop and mobile widths, including 320 px with enlarged text.
- Repository CI and integration tests gate this release.

## Current limits

No real homelab data has been migrated. Automatic Orbis installation and rollback, host package updates, and multi-server pairing are not included. Do not replace a production Runtipi installation with this preview.
