# Orbis v0.1.0-beta.83

- System updates now includes a reviewed server restart with automatic reconnection. Existing installations need one verified installer refresh to enable the new host-helper capability.
- Monitoring collects history while visible clients are connected and pauses when Orbis is unused, preserving existing history.
- Search expands into the system bar with a separate results panel and keyboard navigation.
- Improved navigation and dock transitions, activity labels, dashboard space allocation and theme consistency in Monitor.
