# Orbis beta 34

## Frozen runtime dependencies

- The production image copies its required external packages and transitive dependencies from the frozen Bun install. It no longer performs an unversioned npm installation.
- The packaged dependency manifest records the lockfile hash and resolved versions while preserving nested version resolution.
- Every architecture build checks module versions, native password hashing and transformation under its production Node runtime before publication.

## Responsive navigation and alignment

- Window controls are reserved for screens at least 1100px wide and 640px high. Phones, tablets and short viewports use ordinary pages, compact headings and dock navigation.
- Resizing preserves the mounted form and saved desktop placement. A minimized desktop link opens its section immediately on a small screen, preserving other query values and the hash.
- Large-screen tools stay between the system bar and dock. Minimize/restore retains the content scroller and reading position.
- Settings title icons, tabs, dividers and forms use a shared gutter. Inherited negative tab margins are removed; the divider follows every visible tab row.
- Enlarged Appearance choices reflow so Graphite and Sandstone remain whole. Focused page controls clear the measured sticky bar and dock, including reverse Tab on short screens.
- Store dialogs restore focus to a surviving target after deletion or a pending close. Delayed list growth keeps the focused action visible.

## Verification

Source checks pass 420 backend tests and seven runtime packaging cases, including standalone native hashing and Node verification. A local Linux arm64 image also verified a password hash made by beta32’s newer runtime library. UI checks cover 20 Settings size/theme/text groups, the four-width native route matrix, responsive window/page transitions, pending updates and 16 app-store flow groups. [Responsive screenshots and measurements](https://github.com/twentylines/orbis/tree/main/screenshots/page-navigation) show the corrected layout. Source captures use intercepted development data; they are not released-image evidence.

This remains a preview. Publication is followed by a reviewed OTA and released-image inspection on the isolated test homelab. Copied real-data migration, other browsers, physical devices and complete production acceptance remain open. Hades has not been changed.
