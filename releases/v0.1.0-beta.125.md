# Orbis 0.1.0 beta 125

- Keep Apps and Themes controls in place while Store filters change, and use compact illustrated app cards with an Install action.
- Suggest available apps for media, game hosting, development and other server uses. Hide individual suggestions for a visit, turn off a category, or disable recommendations in Settings.
- Add Emby, Jackett and more media-library tools to guided setups. Reuse installed players and download clients, and configure selected apps together before installing them.
- Keep stack configuration available during installation and recovery. Reconcile acknowledged operations with their exact task before allowing a failed installation to be retried.
- Keep the populated sign-in card visible until its loading transition begins, and add a protected exit from custom-app creation.
- Use direct action labels such as Downgrade and Restart, with Initialising shown while preparation begins.
- Improve nearby-server hints on private networks while retaining HTTPS validation and approval before access or transfer.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
