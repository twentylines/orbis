# Orbis 0.6 beta 1

- Added the experimental Time Machine interface.
- Refined Settings, OLED and loading animations.
- Simplified backup, restore and reset flows.
- Updated the installer and monitoring.

Time Machine capture and restore require a compatible Orbis host service. Runtipi remains at 4.10.1.
