# Orbis beta65

## Installation

- Include a release-bound Python launcher and a small helper archive with manifest and per-file hashes. Download helpers from the same source commit and release as the core image.
- Detect supported Runtipi installations and offer Keep or Fresh replacement, with a private backup and recovery journal.
- Initialize an empty Linux server directory with pinned PostgreSQL 17, RabbitMQ 4 and Traefik 3.6 images. Keep database and queue ports private.
- Record interrupted initialization and resume startup without overwriting an environment or app data already accepted by the controller.
- Enable the restricted host administration service through a dedicated read-only socket mount. Resume identical partial helper copies and retain their configuration in enrollment checks.

## Docker compatibility

- Restrict startup network cleanup to unused networks explicitly labelled `orbis.managed=true`, preserving other Docker networks.
- Require the corresponding image capability before a new installation or a controller restart through the installer.
- Keep the host-operation lock inherited by Docker subprocesses so recovery cannot race a command still finishing after its caller exits.

This is a Linux systemd prerelease. Existing Runtipi replacement supports the 4.10.1 compatibility base; unsupported versions and layouts require review. Keep installation backups and recovery files. See [installation requirements](https://github.com/twentylines/orbis/blob/main/INSTALLATION.md).
