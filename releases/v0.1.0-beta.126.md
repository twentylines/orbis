# Orbis 0.1.0 beta 126

- Improve the latest-release installer with a release chooser, forward-moving terminal stars and real stage progress. Explain the 64-bit ARM/x86 Linux requirement and report the correct server address. Docker Engine 25+ and Compose remain prerequisites.
- Add HTTPS setup guidance for private networks and clearer explanations when nearby discovery is unavailable.
- Create cluster pairing codes without re-entering a password, while keeping approval checks when connecting servers.
- Keep saving feedback beside Save without shifting Settings forms. Align the Store app-update switch and refine dropdown corners, search focus and recent-operation spacing.
- Reorganise Settings into clear categories, with search for individual options and common misspellings. Keep drafts when switching categories and show unsaved changes without moving the form.
- Give Orbis, apps and system packages separate automatic-update schedules. System updates require a chosen time before they can be enabled.
- Refine compact Store cards, direct installation options and installed-app-aware suggestions. Keep suggestion and automatic-app-update controls together in Store settings.
- Add high-resolution photographs matched to the colour presets, with new rose and blue landscapes. Keep the open Home layout and installed theme-pack images.
- Save read task alerts to the signed-in account so reloading does not bring old alerts back. New failures still appear, and refreshing a task no longer makes it unread again.
- Confirm theme changes before applying them, show forward-depth loading, and reload into the selected theme. Keep recovery controls available if applying fails.
- Keep build details and downgrade options visible, with clearer spacing in Updates.
- Make completed backups compact with Download and Remove actions. Keep removal confirmations beside the selected backup and give destructive actions consistent red icons.
- Fix settings-save races across sign-in sessions, hidden dialogs covering other categories and app actions used before their details finish loading.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
