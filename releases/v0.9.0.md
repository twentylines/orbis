# Orbis 0.9

- Smoothed the opening frames of the Orbis loading animation and kept menu glass visible throughout flyouts.
- Improved Home editing, app and toolbar drop targets, switch sizing and heading alignment.
- Stabilised Apps and Store scrolling, with the dock following the pane receiving input and catalogue items loading earlier.
- Filled the available page area across window sizes and kept app-detail transitions from resetting catalogue position.
- Added inline app-opening, appearance, text-size, density and motion settings to search. Find an app now opens the Apps category.
- Made installer stars branch outward with installation progress while the Orbis logo plays independently.
- Added clear Sentinel download, verification, installation, health-check and recovery progress.
- Reduced repeated Docker inspections during update preparation. Controller updates no longer create an automatic data backup, and interrupted cutovers report when local recovery review is needed.
- Added guarded automatic recovery for stale controller Docker socket bindings after the Docker engine replaces its socket.

Use the current Orbis Host service for this release. The installer upgrades the Host service before a controller update; earlier Host helpers reject the new controller capability before downtime.
