# Orbis beta 36

## System status themes

- System status in Home and Monitor follows light/dark mode and the selected colour preset. Its gradients and dividers use theme surfaces, with a separate preset tint that remains available in dark mode.
- Readings use theme text colours with stronger small-label contrast. The 3D server retains distinct front, side, top and bay materials, tinted to the selected preset.
- Live/stale indicators keep their status colours. Monitor retry messages and resource meters also use theme tokens.

## Window header containment

- Removed bright window, top-bar and dock rims. Coloured titlebars and the top bar use the dock's subtle blur, with palette tint and an opaque themed fallback where blur is unavailable.
- Section slides capture the desktop window content separately, keeping the titlebar outside that snapshot layer so its blur can sample the actual wallpaper. Phone page slides retain their existing layout.
- Desktop titlebars clip to the frame's rounded corners without a pale parent layer or separate bright inset seam. Blur is confined to the chrome instead of the entire desktop window.
- Desktop frames cannot scroll a fixed header under their rounded edge when browser focus moves. Tool content still scrolls normally; unusually tall headers retain whole-frame scrolling.
- The real window audit now waits for settled navigation and checks header padding, frame scroll position and Home's initial document position before accepting a screenshot.
