# Orbis v0.1.0 beta 14

## Since beta 13

- The Update Center reads Ubuntu 24.04 host upgrade candidates from the installed host helper's APT cache. It shows installed and candidate versions, repository, download size, security origin, cache age, and whether the host requests a reboot.
- An operator can open the distribution changelog for one exact candidate. The host helper obtains it through APT with a fixed argument list and a timeout; the browser cannot supply a command.
- The helper upgrader accepts the beta 13 script set and installs the new package reader while preserving the existing enrolled core and private Unix socket.

## Current limits

Package installation and reboot controls are not present in this build. The APT reader currently supports Ubuntu 24.04 only. Real homelab data, external mounts and named volumes, amd64 runtime, and multi-server pairing remain unverified or unimplemented. This release is for isolated testing, not a live Runtipi replacement.
