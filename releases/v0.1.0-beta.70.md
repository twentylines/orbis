# Orbis beta70

## Installer

- Preserve shared app overrides in `user-config` during replacement and rollback. File managers can keep running with writable access to those app overrides. The core Compose override remains checked for unexpected changes.
- Report real checkpoint conflicts with the container name, ID, writable mount and affected backup path. Containers writing controller metadata still block an unsafe checkpoint.
- Recognize compatible Compose long-syntax and absolute database bind mounts through normalized configuration. Keep the local writable database and version checks.
- Offer another dashboard port when an existing service occupies one. Check custom Docker bindings and native IPv4/IPv6 listeners before creating a new installation.
- Refuse to treat orphaned managed containers as an empty server. Preserve existing Docker workloads during new setup.
- Replace duplicate loading effects with one animated bar showing completed stages, clearer prompts and a compact presentation for narrow terminals. Plain output and reduced animation options remain available.

```sh
curl -fsSL https://twentylines.github.io/orbis/install | sudo python3
```
