# Orbis 0.6.1 beta 2

- Controller updates preserve the running reverse proxy and managed applications while replacing Orbis, with verified startup and recovery checks.
- Added protected, persistent reset storage for reviewed legacy installations. Storage failures no longer appear as an incorrect password.
- Fixed full-backup checks rejecting supported Docker socket and timezone mounts. Reset recovery files are excluded from new backup exports.
- Kept the update confirmation visible during verification, clarified its progress, and removed “Open last update plan”.
- Fixed maintenance connections interrupting long requests, uploads and live progress.
- The installer can receive verified updates independently of an Orbis release.

Time Machine remains experimental. Legacy proxy layouts require a protected migration before coherent capture and retained restoration can run.
