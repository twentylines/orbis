# Orbis beta77

## Appearance

- Set interface text size from 85% to 150%, with a reset to the default size.
- Save text size with your account and include it in appearance exports. Apply the cached size before the interface loads.
- Use relative text sizes across pages, menus, dialogs and notifications.

## Layout

- Give narrow screens more room while keeping the workspace aligned with the system bar.
- Fit the connected address between phone controls, and give connection messages their own row.
- Preserve word boundaries in app summaries and keep full app and package identifiers accessible when shortened.
- Keep long dialog titles within the available width, with full names available to assistive technology and on hover.
- Put wide description tables in a keyboard-scrollable area and preserve whole words inside their cells.
- Align installed and available package versions, and use clearer package changelog buttons.
- Refresh the light and dark appearance screenshots.
