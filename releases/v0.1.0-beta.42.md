# Orbis beta 42

## Host devices in Monitor

- Show host mounted filesystem capacity, network interfaces and whole-device disk activity through the restricted Linux host service. Keep Orbis core storage and network readings under their own headings.
- Use actual elapsed time for network and disk rates. The first reading, counter resets, replaced devices and long sampling gaps remain unavailable until two recent samples exist.
- Show missing, partial, stale and omitted readings explicitly. Filter temporary container mounts and avoid adding layered devices into a misleading total.
- Share one bounded collector across viewers, limit each group to 32 items and pause browser polling in background or minimized views. A blocked filesystem cannot occupy the helper's HTTP handler or create repeated collector workers.

The installed host service must be upgraded from a reviewed checkout to include `orbis-host-telemetry.py`. Updating the core image alone does not replace the host service. Older helpers keep their existing operations and Monitor reports the missing capability. See [HOST-SERVICE.md](https://github.com/twentylines/orbis/blob/main/HOST-SERVICE.md).

## Layout and keyboard focus

- Wrap mount paths at directory boundaries. Keep complete accessible identifiers when an unusually long segment needs ellipsis; reflow labels and values as text grows.
- Restore Retry focus to the surviving heading after successful loading, and retain focus on a different control the user has selected.
- Give chart axes room for their labels and place inspection details below the graph. Enlarged text no longer overlaps the plot or the following rows.
- Strengthen small-label contrast on pale presets while retaining theme colours.
- Prevent inherited smooth page scrolling from moving a newly focused control behind the dock. Section and search animations remain unchanged.
- Retain the shared translucent palette blur for the system bar, coloured desktop titlebars and dock, without bright frame rims.

## Verification boundary

Backend authentication, validated socket transport, bounded counter collection and an actual source Unix handler in the owned arm64 Linux guest pass. Root capacity matches host `statvfs`; two distinct samples produce real interface and disk rates. This probe does not update the installed helper or core.

All 439 backend, 78 common and 85 Python tests pass, with frontend/backend types and bundles. Compiled-source Chrome passes 16 layouts, 35 states, 12 preset combinations and ten chart cases, with no browser errors, unexpected mutations or cleanup failures. [Current captures and measurements](https://github.com/twentylines/orbis/blob/main/screenshots/host-devices/README.md) retain whole-word, interior-padding, native-focus, exact refresh-scroll and contrast checks. Published-image, installed-helper upgrade and reviewed OTA checks remain separate acceptance steps until recorded in [DEPLOYMENT.md](https://github.com/twentylines/orbis/blob/main/DEPLOYMENT.md).

This remains a development prerelease. Host-process ranking, sensors/GPU, richer history, full theme packs, multiple homelabs and complete migration/production acceptance remain open. Hades is unchanged.
