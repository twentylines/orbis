# Orbis 0.1.0 beta 121

- Discover apps through relevant server collections, with media, game-server, development and AI suggestions that account for installed apps.
- Review a media stack one app at a time, including optional library tools and a download client, while preserving each app’s installation settings.
- Create encrypted backups containing server configuration and managed app data; upload, verify and review a backup before explicitly replacing this server.
- Restore a backup from the onboarding card, with upload progress, compatibility review, recovery controls and clear authentication requirements.

- Keep browser event streams from blocking a consistent backup snapshot.
- Highlight high resource use and sustained CPU, memory or hardware temperature problems, with delayed readings and recovery handled separately.
- Give hardware warnings comfortable spacing and shorten password-reset instructions.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
