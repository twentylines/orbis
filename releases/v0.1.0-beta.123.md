# Orbis 0.1.0 beta 123

- Pair with another Orbis server over HTTPS using its private certificate authority, confirm the peer fingerprint, and authenticate with that server's account, including a one-time code when enabled.
- Keep pairing credentials and certificate trust scoped to the selected server, and retain account-scoped pending changes while cluster state reconnects.
- Browse a more compact Store with full-width app artwork cards, collection shelves and layouts that adapt to smaller screens.
- Combine colour and wallpaper in Customisation, smooth setup transitions, and finish setup on Home.
- Simplify backup upload and server transfer with guided steps, clearer file selection and measured progress in the setup card.
- Add an off-by-default automatic update setting for Store apps, including future installations, while retaining per-app manual choices and custom schedules.
- Remove lingering pointer focus highlights from closed dropdowns and improve search icon contrast in light mode.
- Fix update checks when no Stable release has been published.
- Generate the installer archive with a fixed compression level for reproducible release assets.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
