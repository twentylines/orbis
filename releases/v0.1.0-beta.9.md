# Orbis v0.1.0 beta 9

This is a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 8

- The Update Center now reads GitHub's public release feed and immutable tagged Markdown notes through a cached, authenticated Orbis endpoint. This keeps changelogs visible when the anonymous GitHub API quota is exhausted.
- The published-release verifier can use a direct GitHub release asset, Git tag resolution, and tagged notes if the GitHub API returns a rate limit response. It still validates the manifest and exact GHCR image index digest and requires amd64 and arm64 entries.
