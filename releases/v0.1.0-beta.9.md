# Orbis v0.1.0 beta 9

This is a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 8

- The Update Center now reads GitHub's public release feed and immutable tagged Markdown notes through a cached, authenticated Orbis endpoint. This keeps changelogs visible when the anonymous GitHub API quota is exhausted.
- The published-release verifier can use a direct GitHub release asset, Git tag resolution, and tagged notes if the GitHub API returns a rate limit response. It still validates the manifest and exact GHCR image index digest and requires amd64 and arm64 entries.

## Verification

- Beta 8's published arm64 image was installed from beta 7 through the restricted host service in an isolated Linux VM. The core reached the exact digest and healthy state; the previous tree snapshot verified; the inherited account and Whoami app remained.
- Beta 8's Update Center read the real completed host job. Chrome found the GitHub API rate limit that prompted this fix. The public feed, tagged notes, direct manifest, and verifier fallback were then exercised live; local Python and backend tests passed.
- CI and integration tests gate this release. Runtime validation of this tag's image and a browser-clicked update will follow publication.

## Current limits

The host service still needs a supervised Linux installer and a full browser-clicked update rehearsal. Managed apps must be stopped; external mounts and Docker volumes are outside the current snapshot path. Host operating system package updates, real homelab migration, and multi-server pairing remain open. Hades has not been touched.
