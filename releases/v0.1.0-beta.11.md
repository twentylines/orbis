# Orbis v0.1.0 beta 11

This remains a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 10

- Added a guarded first-install tool for the restricted Linux host service. It verifies the enrolled image, explicit Docker context, read-only core socket mount, and matching host/container mount inode before copying root-owned scripts and enabling systemd. Setup checks the socket from both sides and rolls back its own files if startup fails.
- Preserved the host socket directory across systemd service restarts so the running Orbis container does not keep an orphaned bind mount.
- Refined the long Monitor and Update Center pages: the dock no longer covers those detail views, mobile release notes use normal page scrolling, and keyboard users can focus the desktop changelog region.

## Verification before publication

- The beta 9 Update Center discovered beta 10's public release and completed a real browser-clicked review and install in the isolated arm64 Linux VM. It showed the exact digest and snapshot estimate, returned a job ID, and reached the published beta 10 image with four healthy core services. The previous tree snapshot verified and the account and Whoami app remained.
- The first installer rehearsal exposed a stale container bind mount after a manual unit was removed. A targeted test covers the new mismatched-inode rejection; recreating only the isolated core restored access. The corrected unit survived a service restart and full VM stop/start. A clean corrected install returned an active service with root-owned private files and a reachable socket inside the core.
- Local validation covers the socket-mount checks, confirmation guard, backend and frontend type checks and builds, and browser layout review. Repository CI and integration tests gate publication.

## Current limits

The setup tool works only after a reviewed stock adoption and socket mount. It does not upgrade an existing helper, capture external mounts, or validate a real homelab backup. Host operating system package updates and multi-server pairing remain open. Hades has not been touched.
