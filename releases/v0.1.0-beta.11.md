# Orbis v0.1.0 beta 11

This remains a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 10

- Added a guarded first-install tool for the restricted Linux host service. It verifies the enrolled image, explicit Docker context, read-only core socket mount, and matching host/container mount inode before copying root-owned scripts and enabling systemd. Setup checks the socket from both sides and rolls back its own files if startup fails.
- Preserved the host socket directory across systemd service restarts so the running Orbis container does not keep an orphaned bind mount.
- Refined the long Monitor and Update Center pages: the dock no longer covers those detail views, mobile release notes use normal page scrolling, and keyboard users can focus the desktop changelog region.
