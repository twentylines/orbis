# Orbis beta79

## Workspace

- Arrange Home with draggable widget cards and app icons, visible drop targets and keyboard move controls. Save waits for account changes to finish syncing.
- Keep up to 512 apps in a saved pin order. Remove the separate pin and install buttons from Home.
- Keep large pinned-app lists in a scrollable Home area on larger screens, with ordinary page scrolling on phones.
- Improve compact layouts and place CPU, memory and storage readings together. Show reported CPU clock speed only when available.
- Show Running for apps without configured Docker health checks. Count existing checks correctly when an app includes unchecked helper containers, while retaining real unhealthy, starting and stopped states.

## Navigation and appearance

- Coordinate every Home tile and widget during entry, including content loaded later.
- Improve card resizing, browser history transitions and login/logout sequences. Short navigation no longer flashes loading wheels; longer requests show feedback inside the page.
- Open Store app details beside the catalogue on larger screens, with ordinary pages on phones.
- Give every colour preset matching light and dark palettes, including neutral Graphite. Apply theme changes together across actions, logos and status panels.
- Correct the first minimized app's padding, window restore geometry and resizing during motion. Keep ongoing operations beside the dock with expandable details.
- Use a subtle accent treatment for the expanded search field instead of a rectangular focus outline.

## Settings and updates

- Move app-store refresh controls to Store and App Stores settings, remove the Actions tab and enlarge log terminals on larger screens.
- Keep the desktop and update status available during an Orbis restart, then refresh once the verified target is healthy.
- Support copying pairing codes on local HTTP addresses, with a selectable fallback if the browser blocks copying.

```sh
curl -fsSL https://twentylines.github.io/orbis/install | sudo python3
```
