# Orbis v0.1.0 beta 10

This is a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 9

- Added a systemd unit for the restricted host service. It creates private runtime and snapshot directories, starts after Docker, survives Docker restarts, and resumes after a VM boot.
- The fixed desktop dock moves aside when the Update Center changelog is open, so it does not cover release text.
