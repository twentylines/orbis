# Orbis v0.1.0 beta 10

This is a development preview for isolated homelab testing, based on the Runtipi v4.10.1 CLI data and application layout.

## Since beta 9

- Added a systemd unit for the restricted host service. It creates private runtime and snapshot directories, starts after Docker, survives Docker restarts, and resumes after a VM boot.
- The fixed desktop dock moves aside when the Update Center changelog is open, so it does not cover release text.

## Verification before publication

- The unit passed `systemd-analyze verify`, a service restart, and a full stop/start of the isolated Colima Linux VM. The socket returned the saved host job after boot and the beta 8 core returned to healthy state. The first boot test exposed a Docker service dependency issue that was corrected before this release.
- The published beta 9 image booted on the isolated VM at its exact digest with the original account and Whoami app. Chrome displayed the tagged changelog at desktop and phone widths without page errors or horizontal overflow. An open changelog exposed a fixed-dock overlap; this release includes the spacing correction.
- Backend and frontend type checks, tests, production bundles, and repository CI/integration gate this release. Runtime validation of this image and a browser-clicked core update follow publication.

## Current limits

The systemd unit requires manual installation on an already enrolled host. Managed apps must be stopped for a core update, and external mounts or Docker volumes are outside the current snapshot path. Host operating system package updates, real homelab migration, and multi-server pairing remain open. Hades has not been touched.
