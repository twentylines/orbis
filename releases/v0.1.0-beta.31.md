# Orbis v0.1.0-beta.31

## Changes

- App-store errors appear inside the open dialog, keeping the form and retry action accessible. Successful actions still use themed notifications.
- App-store tables give names, status and actions consistent space. Long repository addresses have an accessible full link, and keyboard focus reveals the complete action and focus marker.
- Enlarged text can scroll within an app-store dialog while the action remains available.
- Switch tracks align with their labels as text grows. Each switch has a stable associated label that can be clicked to toggle it.
- A failed repository removal keeps the store registered and reports an error. Removing an already absent repository remains safe to retry.
- Store removal waits for an app installation to reserve its database row. Concurrent removals preserve the final store, and stale queued refreshes cannot recreate a removed store.
- The English clone error uses a short, practical message without repeating the repository address.

The inherited Runtipi backend, app configurations and data remain in place. Full production migration acceptance is still in progress; Hades has not been replaced.
