# Orbis v0.1.0-beta.110

## Interface and app windows

- Let clicks outside action menus reach the page, and recover the requested destination when an update removes an older page file.
- Keep dock buttons steady during a mouse press, and keep the selected section consistent with the page being displayed.
- Give simultaneous activity categories their own compact tasks pills, splitting and merging through one continuous glass shape.
- Add notification flyouts and aligned action buttons for opening apps, viewing logs, backups or failed tasks.
- Keep app settings and advanced configuration inside the Apps preview. Restore the app picker when one side of a split closes.
- Preserve working embedded apps when server compatibility checks differ from the browser. Move connection help into the window layout menu.
- Align window layout controls, highlight selected fields from within, and make app cards and management actions more compact.

## Monitor

- Retain the last valid CPU temperature while delayed readings recover, and show its sampling time.
- Distinguish app lifecycle, process restarts and Docker readiness. Add healthcheck details, container search, status filters and bounded lists.
- Offer a confirmed app restart from container health details on the local server.

## Wallpapers

- Show image upload progress and actionable errors, with support for original images up to 32 MB and 64 megapixels.
- Remember the selected custom image in this browser for sign-in and loading screens, without exposing private wallpaper endpoints.
- Improve wallpaper controls, previews and alignment.
- Remove the fixed wallpaper layer's solid fill that can extend into Safari's phone browser toolbar.
