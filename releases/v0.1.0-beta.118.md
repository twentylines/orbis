# Orbis 0.1.0 beta 118

- Use one raised numbered Tasks badge. Unread failures and critical updates turn it red; opening Tasks clears the alert colour without hiding operations still in progress.
- Remove native browser styling, focus fills and halos from the global search field, keeping the expanded bar one continuous surface.
- Open app windows and dialogs without automatically highlighting a toolbar button. Preserve keyboard navigation and restore focus to the window when closing its settings or layout controls.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
