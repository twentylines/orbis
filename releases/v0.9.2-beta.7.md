## Recovery

- Open Sentinel recovery or start the guarded handoff from Settings → About. Updates shows Sentinel version, health and update progress.

## App jobs

- Start app backups and updates from the Orbis CLI. The command shows job progress and reports success after the job completes.
- CLI updates create a backup by default. An app migration still keeps its recovery checkpoint when the optional archive is skipped.

## Installation

- Set protected permissions when generating the proxy configuration for a new installation.
