# Orbis beta62

## Appearance

- Compose, notes, configuration and update-review editors now use the selected Orbis appearance. Gutters, selection, search controls and diff highlights use the same palette.
- Editor search, keyboard focus and drafts survive resource refreshes and appearance changes. Search controls and configuration tabs reflow on narrow screens with enlarged text.
- The initial loading screen uses the browser's saved light/dark mode, colour preset and wallpaper before the application bundle and server preferences arrive.
- Operation notices and log terminals use shared theme materials. Log output retains its own status colours.
- Optional seasonal effects stop when a tab is hidden or reduced motion is enabled. Disabling the effect removes its canvas, timers and listeners.

This is a prerelease. Migration of an existing homelab, external app data and complete device/browser acceptance remain unverified. See [Installation and migration](https://github.com/twentylines/orbis/blob/main/DEPLOYMENT.md) before replacing an existing installation.
