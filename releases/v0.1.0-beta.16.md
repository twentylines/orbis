# Orbis v0.1.0 beta 16

This remains a development preview based on Runtipi v4.10.1. Hades has not been changed.

## Since beta 15

- Reworked the server workspace around a locally bundled alpine and orbital wallpaper, an open application launch area, a live CPU/memory/network instrument panel, and distinct storage and operations surfaces.
- Added a floating system bar and dock with coordinated window, panel, app, hover, press, and search motion. Reduced-motion preferences suppress the animation.
- Secondary views now have an OS-style window header with a working return-to-workspace control.
- Updated the visual presets' chrome and Graphite contrast so the desktop stays readable across the included appearances.
- The visual fixture now captures completed animation states, making screenshots useful for review.

## Verification before publication

- The production bundle, TypeScript checks, and desktop/phone/320px visual flows passed locally. The visual flows exercised navigation, workspace editing and persistence, pinning, the store, updates, monitor, appearance, and checked for page errors and horizontal overflow.
- GitHub CI and integration tests gate image publication.

## Current limits

This is an interface preview, not a finished replacement for a live Runtipi server. The full theme system, multi-server pairing, additional host management, real Hades migration, external mounts and named volumes, and amd64 runtime still need implementation or live validation. The Ubuntu host-update helper remains limited to 24.04 and package changes have no automatic rollback.
