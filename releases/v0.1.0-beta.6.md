# Orbis v0.1.0 beta 6

This remains a development preview for isolated homelab testing. It targets the Runtipi v4.10.1 data and application layout.

## Since beta 5

- Added a host-side update transaction for an already enrolled Orbis CLI installation. It validates the published GitHub and GHCR release, pulls the target digest before downtime, captures a checksum-verified stopped-state tree, and restores the previous release if the new core fails to start.
- Added a shared lock for host start, stop, enroll, and update commands, plus an update journal and explicit recovery command.

## Current limits

The host update command works only after Orbis has already been enrolled on a CLI v4.10.1 installation. It requires managed apps to be stopped and does not capture data on external mounts or Docker volumes outside the installation tree. There is no first stock-to-Orbis installer, browser release apply, host package updater, or multi-server pairing yet. No real homelab data has been migrated. Do not replace a production Runtipi installation with this preview.
