# Orbis v0.1.0 beta 5

This remains a development preview for isolated homelab testing. It targets the Runtipi v4.10.1 data and application layout.

## Since beta 4

- Workspace now has an explicit edit mode. Each of its four widgets can be shown, hidden, reordered, or switched between standard and wide width. A restore action returns the widget layout to its defaults.
- Up to 12 installed applications can be pinned to the front of the launch area. Pins and widget layout are saved per user, and existing preference files receive the new defaults when read.
- The Graphite workspace heading is legible in dark mode. Editing controls adapt to phone widths and enlarged text.

## Verification

- Beta 4's published arm64 image booted healthy on the stopped synthetic Runtipi CLI copy and retained the inherited account, installed app record, and store.
- Targeted preference API tests, TypeScript checks, Biome, and a production bundle passed in the source tree.
- Chrome fixture checks exercised widget editing, app pinning, reload persistence, Graphite, desktop and phone layouts, and a 320px viewport with enlarged editor text. No horizontal overflow or browser errors were reported.
- Repository CI and integration tests gate the release image. Runtime validation of this tag's published image is a separate step after publication.

## Current limits

The host command still requires an already migrated and healthy Orbis installation. There is no first-cutover installer, browser release apply, complete snapshot and rollback controller, host package updater, or multi-server pairing yet. No real homelab data has been migrated. Do not replace a production Runtipi installation with this preview.
