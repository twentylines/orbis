# Orbis beta49

## Keep process readings steady while CPU comparisons restart

When fresh CPU comparisons are temporarily unavailable, keep the previous CPU sample visible with its original timestamp and a clear delayed label. Memory continues to show current readings. Fresh CPU comparisons replace the old ranking; a first sample without history still shows its collecting state.

This prevents the process list collapsing and forcing a scroll jump while a control is focused. No artificial blank space is used to hold the page height. Compact Docker and process panels also use the same padding token so their headings line up.
