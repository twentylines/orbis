# Orbis v0.1.0 beta 1

This is a development preview for isolated homelab testing. It is based on Runtipi v4.10.1 and keeps the Runtipi app lifecycle, store, account, backup, and data services while adding the Orbis browser workspace.

## Included

- Orbis dashboard, app catalogue, applications, settings, system monitor, and Update Center presentation.
- Live authenticated telemetry and per-user desktop appearance preferences.
- Orbis release notes from this GitHub repository and authenticated installed-build metadata.
- A multi-architecture container image published by this release workflow. The attached manifest records its immutable digest and Runtipi compatibility base.
- Read-only migration inventory and release planning for a copied Runtipi CLI v4 installation.
