# Orbis v0.1.0 beta 1

This is a development preview for isolated homelab testing. It is based on Runtipi v4.10.1 and keeps the Runtipi app lifecycle, store, account, backup, and data services while adding the Orbis browser workspace.

## Included

- Orbis dashboard, app catalogue, applications, settings, system monitor, and Update Center presentation.
- Live authenticated telemetry and per-user desktop appearance preferences.
- Orbis release notes from this GitHub repository and authenticated installed-build metadata.
- A multi-architecture container image published by this release workflow. The attached manifest records its immutable digest and Runtipi compatibility base.
- Read-only migration inventory and release planning for a copied Runtipi CLI v4 installation.

## Verified

- Repository CI and integration tests gate this release.
- Clean-install startup, registration, key browser routes, and an official Whoami app lifecycle were tested in a disposable Docker VM.
- A synthetic stock Runtipi CLI v4.10.1 installation with an account, custom core Compose override, official store, and Whoami app booted with a local Orbis image. The inherited app could be stopped and started. Restoring a stopped-state copy returned the installation to stock Runtipi.

## Before production use

This image has not been tested against a copy of an existing homelab, including Hades. Core image installation and rollback are not automated yet. Host operating system updates and multi-homelab pairing are not included. Use only on an isolated test host with a complete stopped-state backup; do not use this preview to replace a production Runtipi installation.
