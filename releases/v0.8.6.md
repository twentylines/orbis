# Orbis 0.8.6

- Refreshed Monitor, Task Centre, Apps, Store and Updates with more consistent layouts and controls.
- Added richer colour presets, wallpaper-derived colours and autosaving custom colour sliders.
- Simplified appearance settings and improved dark glass, selected controls and colour retention at lower opacity.
- Smoothed sign-in, sign-out and workspace loading, with blur present from the start of transitions.
- Added scroll progress to the compact navigation button and removed redundant side scrollbars from main panes.
- Improved setup swatches, account-card styling, application summaries and enlarged-text layouts.
- Added a clearer installation flow for the drive-health tools.
- Improved search actions and system information.

Time Machine remains experimental. Full restore and standalone recovery workflows are still being completed.
