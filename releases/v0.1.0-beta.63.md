# Orbis beta63

## Navigation and app launchers

- Navigate between full pages from the dock with directional slide transitions. Phones and tablets use ordinary pages.
- Open apps through lightweight desktop launchers. Minimize them into a compact tray above the dock with spring motion, then select an icon to restore. Minimized launchers stop polling app details.
- Preserve keyboard focus, enlarged-text spacing and reduced-motion preferences. App interfaces open in separate browser tabs.

## Docker apps

- Detect Docker workloads outside the Orbis app library. Review their containers and persistent storage before uninstalling.
- Retain bind-mounted data and Docker volumes when removing reviewed containers. Protect Orbis infrastructure and registered apps. Automatically removed containers require separate handling.
- Show readable app names in Tasks.

## Installation support

- Add controller hold/resume modes for an independent installation executor. Held controllers skip app commands, background jobs and app bootstrap; pending work prevents an unsafe resume.
- Declare installer protocol support in the release manifest and image label. Older releases remain valid update targets but cannot be selected for a takeover that requires this protocol.
- Include host tools for reviewing, stopping and recovering existing app containers, plus verified backups of installation files, external bind mounts and local Docker volumes.

The complete two-choice replacement installer is still in development. These tools do not establish a completed migration of an existing homelab. Review [installation requirements](https://github.com/twentylines/orbis/blob/main/INSTALLATION.md) before replacing Runtipi.
