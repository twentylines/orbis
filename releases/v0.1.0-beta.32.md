# Orbis beta 32

## App-store connection recovery

- Stalled store connections now abort after 30 seconds without network progress. Clone and fetch each have a ten-minute overall limit.
- Cancellation stops the underlying HTTP/HTTPS transfer. Repository locks remain held until Git and staging cleanup finish, so a queued removal or installation cannot race abandoned work.
- Failed refreshes retain the working catalogue. Failed new clones remove their staging files before retry.
- Custom homelab ports, redirects, Basic authentication, trusted TLS agents and compressed responses remain supported. Transport streams use backpressure; Git still buffers packfiles internally.
