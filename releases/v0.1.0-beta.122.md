# Orbis 0.1.0 beta 122

- Restrict changes to shared server settings, including HTTPS and domain settings, to authenticated operator sessions. Account preferences remain separate.
- Prepare isolated restore workers on managed Docker networks identified by either their exact name or full ID, and explain recognised backup conflicts clearly.
- Transfer an encrypted configuration and app-data backup between Orbis hosts, with a one-use code, source approval and backup review before restoring.
- Preserve the receiving server’s HTTPS address, certificates and cluster membership during restore. Review settings sync again after restoring accounts.
- Connect over private HTTPS, including an explicitly confirmed local certificate with hostname verification. Nearby discovery is optional and never grants trust.
- Choose which appearance and update settings a paired server receives. Consent, conflicting changes and host-specific settings remain visible and separate.
- Open the app catalogue directly, with app previews and relevant collections beside it on larger screens.
- Keep media-stack choices evenly sized and comfortable on phones, with fluid transitions between Store views.
- Find theme packs in the Store. Install, apply, update, roll back or remove the bundled Alpine, Tideline and Woodland packs.
- Keep the selected theme and its photograph through sign-in, sign-out and loading, while preserving personal wallpaper and appearance choices.
- Use the same Orbis dropdowns for nearby interfaces, transfer backups and theme versions.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
