# Orbis 0.1.0 beta 117

- Keep expanded search transparent when its field has keyboard focus, removing the rectangular fill inside the search bar.
- Restore the X on notification dismiss buttons. Show unread task alerts as a red exclamation badge on the opposite side of the Tasks button from its activity count, and clear the alert when Tasks is opened.
- Make wallpapers follow the selected colour by default, including older settings that never explicitly chose a fixed wallpaper. Explicit fixed photographs and uploaded images keep their selection.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
