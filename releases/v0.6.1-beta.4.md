# Orbis 0.6.1 beta 4

- Added encrypted exports for selected settings, dashboard layouts, wallpapers, themes and saved Time Machine captures.
- Completed exports now offer a Download action. Creating a settings export does not capture live app data or media.
- Restore shows the export's contents and lets you choose what to apply. Unselected settings stay unchanged.
- Interrupted settings restores provide an authenticated recovery action and preserve saved exports.
- Improved shutdown of background requests and queues.
- Added protected migration support for legacy installation layouts and local HTTPS certificates.
- Restore workers preserve read-only proxy configuration when the restore keeps the existing network settings.

Time Machine and full app restoration remain experimental. Some older installations still need a reviewed storage migration before updates or Time Machine can run.
