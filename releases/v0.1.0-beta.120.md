# Orbis 0.1.0 beta 120

- Slide the selected option consistently across Updates, Settings, Monitor, search scopes and task filters, with motion confined to each control.
- Give Home app shadows room to fade, align sensor labels and app link icons, and remove unintended sensor-heading underlines.
- Animate dragging a maximized app back to the top edge using the same transition as side snapping.
- Add authenticated restore and recovery controls for encrypted server backups, including cancellation before replacement starts and safe recovery after interruption.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
