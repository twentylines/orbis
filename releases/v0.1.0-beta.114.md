- Repair update-channel setup on fresh and migrated installations, keeping channel choices in protected policy storage.
- Replace indefinite release checks with actionable retry states and consistent spacing around loading and error cards.
- Keep the update icon spinning while Orbis updates, close the confirmation after starting, and shorten task-pill status labels.
- Carry critical-update warnings forward when a newer release includes security fixes missing from the installed version.
- Use consistent hour and minute controls for automatic updates, follow the server’s timezone, and show its current time below the schedule.
- Remove bright frames from minimized-app buttons and use a soft, themed fill for keyboard focus.
- Reshape Monitor into focused usage, performance and drive-health views, with clearer sensor readings and container details.
- Add host-service support for physical drive health and supported drive self-tests.
- Smooth sign-in, authenticator, password-recovery and loading-card transitions, and keep authentication errors inside the card with consistent account-error messages.
- Refine catalogue spacing, app configuration panels and custom-app forms, including shared themed dropdowns and controls.
- Refresh appearance settings with a compact accent-colour flyout and clearer wallpaper upload and image-layout controls.
- Improve About links, app-store management, form feedback and keyboard focus across compact and enlarged layouts.
- Strengthen embedded-app checks to avoid treating an uncertain cross-origin response as a confirmed failure.
- Add backend support for encrypted full-server backup export, authenticated upload review and verified restore staging. The full restore interface and host-to-host transfer are still in development.

This is a Nightly development build, not the v1 release candidate. The larger Store redesign and remaining restore, transfer and cluster-sync work are still in progress.

The new drive-health features require the matching Orbis host service. Updating the dashboard image alone does not replace an older helper. Runtipi remains at 4.10.1; this release does not upgrade Runtipi.
