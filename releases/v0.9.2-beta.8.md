## Updates and recovery

- This same-base release updates the recovery worker before an installation moves to the Runtipi 4.12 base. Install and verify this release before applying the 4.12 update.
- An interrupted update can reclaim its disconnected progress sockets after verifying that the original worker has stopped.
- Sentinel 0.1.0-dev.25 recognizes a deliberately deferred observer socket while the original Host process remains running. The observer socket must be active after Host restarts.
