# Orbis v0.1.0 beta 19

## Desktop polish

- Fixed header alignment on hover, theme-toggle width changes and tablet brand overlap. Header and content now share consistent edge spacing.
- Removed bright white button ridges, window outlines, double dialog frames and the extra dialog gap. Root and overscroll backgrounds follow the desktop mode.
- Shared theme tokens with dialog and menu portals, improved dark dialog text contrast, and coordinated Store form controls with Orbis surfaces.
- Simplified Appearance's repeated headings, moved bulk app controls into an expandable toolbar, and replaced floating update ribbons with inline notices. Docker health remains beside each installed app.

## Server metric history

- Monitor now records CPU, host memory and core-network activity on the server, including while no browser is connected.
- Added 5-minute, 1-hour, 24-hour and 7-day ranges, with range selection preserved in the URL. Charts show actual time positions, averages, peaks and missing-data gaps.
- Added pointer and keyboard sample inspection. CPU source changes remain distinct; unavailable values are never replaced with zero.
- Added a bounded seven-day minute journal with periodic compaction, private permissions, restart persistence, corruption preservation and explicit storage/collector warnings. Graceful shutdown flushes the partial minute; forced termination may lose the unsaved minute.
- Rebalanced Monitor's storage/network sections. No additional monitoring stack or chart library is required.

## Remaining work

Desktop window management, complete personalisation/theme packs, host disks/network/process/sensor telemetry, per-container history, copied real-data migration and multi-server pairing remain incomplete. amd64 runtime and production cutover remain unverified.
