# Orbis 0.6.1 beta 3

- Fixed setup failing with Time Machine enabled when Orbis is opened using a local HTTP address.
- Fixed the same browser compatibility issue affecting sign-in session recovery.
- Improved setup card rendering during animated transitions.
- Verified image downloads can finish when Docker omits individual layer progress events. Unknown download sizes remain unknown.
- Fixed update preflight rejecting normal read-only timezone mounts.
- Independent installer publication now includes changes to every packaged helper.

Time Machine remains experimental. Legacy proxy storage migration and full backup restoration remain under repair.
