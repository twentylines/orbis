# Orbis beta60

## App data permissions

- Preserve existing app data permissions during start, stop, restart, update and configuration regeneration, including after a backup restore.
- Prepare initial installation and reset data before startup. Keep permissions on private files subsequently created by the app.

## Backup controls

- Keep long backup identifiers accessible on narrow screens without orphaned letters in the list. Restore and delete dialogs retain the complete filename.
- Use the same themed button controls for choosing and changing an upload file. Show the complete selected filename separately.
- Show an invalid file selection beside the picker and clear the previous selection. Keep the upload disabled until a valid file is chosen.
- Keep the upload title, close button and footer visible with enlarged text while the dialog body scrolls.

This is a prerelease. Migration of an existing homelab, external app data and complete device/browser acceptance remain unverified. See [App backups](https://github.com/twentylines/orbis/blob/main/BACKUPS.md) for storage and recovery requirements.
