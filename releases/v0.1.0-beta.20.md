# Orbis v0.1.0 beta 20

Development preview based on Runtipi v4.10.1. Hades remains unchanged.

## Application workspace

- Shared official and custom app details with a responsive identity header, lifecycle state, Docker health, installed-version facts and existing lifecycle actions.
- Added per-app container resources and operation history, filtered by the complete application URN. The task centre can retain or clear that application scope.
- Made sections follow URL changes, keyboard navigation, browser history and reload. Disabled unavailable sections and explained stopped container logs.
- Preserved required installation fields, exposure/configuration controls, update review with backups enabled by default, generated Compose read-only access, and backup/reset/remove semantics.
- Fixed custom app Update routing and Remove visibility, and reset the optional backup-removal choice when its dialog closes.

## Alignment and materials

- Matched Workspace action heights and app-card title, notice and health slots. Removed hover movement that broke their shared baselines.
- Standardised system-bar icon sizes and removed theme-icon hover growth. Controls sit on whole CSS pixels and retain their bounds during interaction.
- Coordinated app sections, files, editors and backup empty states with light/dark mode. Improved menu row spacing, viewport insets and tablet dialog width.
- Restored focus to the More button after closing dialogs opened from its menu. Updated desktop, phone and narrow screenshots after independent inspections.
- Padded dock labels, added the configured server IP to connection status, and centred the complete 3D server silhouette on small screens. Restored its hover tilt.
- Fixed command-search keyboard containment, regional language fallbacks and Settings section history. Settings now links to the actual Update Center.

## Container logs

- Cancel stale sources and pending retries when a log panel closes or its application changes. Line-limit changes reconnect with the new limit.
- Show actual connection state and bound authenticated log requests to 1–1000 lines. Invalid query parameters are rejected before opening a reader; unauthenticated requests return HTTP 401. A post-release check found that the production interceptor reports invalid queries as HTTP 200 SSE error events rather than HTTP 400 JSON. The next iteration fixes this at the guard boundary and retains an interceptor regression test.

## Verification and remaining work

The release is gated by types, build, backend/common tests and integration tests. Chrome fixtures cover responsive geometry, navigation, lifecycle form validation, exact-app resource/task scope, editor read-only behaviour, cancelled destructive actions and log-stream cleanup. `VISUAL-QA.md` records the independent inspection matrix.

This remains an incomplete product preview. `ACCEPTANCE.md` retains the outstanding window management, personalisation/theme packs, host telemetry, copied real-data migration, architecture/runtime coverage and multi-server pairing requirements. No production cutover is included.
