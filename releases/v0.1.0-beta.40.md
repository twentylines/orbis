# Orbis beta 40

## Apps and Store

- Installed apps, custom links and action cards share equal grid columns and painted row edges. Tablet rows no longer alternate their inset.
- Store filters align with the title and card gutter. App names and descriptions retain complete text instead of character-count truncation.
- Long custom links reflow with language-aware hyphenation. Notice spacing scales with enlarged text to keep Docker health labels aligned.
- Top bars and coloured desktop headers retain the palette-aware translucent blur and rim-free frame introduced in beta36.

## Updates and authentication

- Check unfinished GitHub release manifests again after 30 seconds. Ready releases retain the normal 15-minute cache; concurrent checks share one request.
- Incorrect, expired or reused authenticator challenges and incorrect enrollment codes return HTTP400. The fifth invalid code remains HTTP429. Stored credentials, encrypted secrets and verification logic are unchanged.
