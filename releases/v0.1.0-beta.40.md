# Orbis beta 40

## Apps and Store

- Installed apps, custom links and action cards share equal grid columns and painted row edges. Tablet rows no longer alternate their inset.
- Store filters align with the title and card gutter. App names and descriptions retain complete text instead of character-count truncation.
- Long custom links reflow with language-aware hyphenation. Notice spacing scales with enlarged text to keep Docker health labels aligned.
- Top bars and coloured desktop headers retain the palette-aware translucent blur and rim-free frame introduced in beta36.

## Updates and authentication

- Check unfinished GitHub release manifests again after 30 seconds. Ready releases retain the normal 15-minute cache; concurrent checks share one request.
- Incorrect, expired or reused authenticator challenges and incorrect enrollment codes return HTTP400. The fifth invalid code remains HTTP429. Stored credentials, encrypted secrets and verification logic are unchanged.

## Verification boundary

The source Apps/Store review covers 1440/768/390/320px in both modes with native and doubled text. It checks each painted row, full copy, loaded icons, comfortable text clearance, actual hyphenation, health-label baselines and native keyboard focus through Store filters. Negative checks preserve the earlier row, link, action-height and health-baseline failures.

All 429 backend tests pass, with frontend/backend type checks and bundles. Timing and authentication regressions fail against the preceding implementation and pass after correction. The separate copied stock account authenticates on published beta39 over scoped HTTPS without reenrollment; its incorrect-code HTTP500 is explicitly rejected pending this release's runtime verification.

These are source checks and separately labelled beta39 transport/browser results. This preview still requires published beta40 image/OTA/login and copied-account HTTP verification. Hades remains unchanged. Full theme packs, multiple homelabs and complete production/migration acceptance remain open.
