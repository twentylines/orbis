## Dashboard and update continuity

- Orbis can update again after the database and queue have moved onto the private Docker network. The updater verifies their live network attachments and preserves their original Docker configuration.
- The dashboard proxy uses the Docker network it shares with Orbis.
- This Nightly keeps the 4.10.1 compatibility base and prepares existing installations for the 4.12 upgrade. Use the guided installer from Orbis 0.9.1 or when the dashboard is unreachable.
