# Orbis 0.8.10

- Refined translucent chrome and smoothed the dock's scroll-to-top controls.
- Added live CPU, memory, network, GPU, and device charts where telemetry is available, with recorded history below where supported.
- Made Orbis update controls easier to find and showed the start of an update while preflight is running.
- Fixed operating-system update preflight for valid APT dependency annotations and separated packages ready to install from deferred candidates.
