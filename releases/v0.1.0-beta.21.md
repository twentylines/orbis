# Orbis v0.1.0 beta 21

Development preview based on Runtipi v4.10.1. Hades remains unchanged.

## Home apps

- Open the Home app picker directly from Applications. Keep selected apps first, or save the option to show every installed app.
- More than three visible apps compact Recent operations and Needs attention. Hide or restore either card in Edit workspace.
- With either lower card enabled, all apps scroll inside their launcher pane. Hiding both lets the launcher expand naturally.
- Fixed launcher/lower-card edge alignment, long picker-name baselines, picker heading clearance and muted label contrast.

## Desktop interaction

- Search expands from its system-bar button into the workspace and contracts back when closed. It searches installed apps, catalogue apps and Orbis sections, including Updates and Settings.
- Support keyboard shortcuts, arrow navigation, modal focus containment/restoration, loading and retry states, stale-query cancellation and interrupted animations.
- Sections slide according to dock order while the header and dock remain steady. Reduced motion disables the animation.
- Keep the server IP visible in compact headers and show reconnecting state alongside it. Align Applications heading controls and retain one shared Home action style.

## Log validation

- Return HTTP 400 JSON for invalid authenticated log queries before SSE headers or log readers open. This repairs the production-interceptor discrepancy discovered after beta 20.
- Retain the production-like interceptor in the HTTP regression suite; authentication, valid streams and the 1–1000-line bounds are preserved.

## Verification and limits

Types, builds, backend/common tests and integration tests gate publication. Local Chrome checks cover desktop, tablet, phone and narrow layouts in light/dark mode; retained Home/search checks exercise app selection, persistence, scrolling, morph endpoints and focus. Independent agents inspect motion, inner padding, error states and responsive geometry.

This remains an incomplete product preview. See `ACCEPTANCE.md` and `VISUAL-QA.md` for remaining window management, personalisation, host telemetry, copied-data migration, browser/architecture coverage and later multi-server pairing. Publication alone does not establish production readiness or authorize a Hades cutover.
