# Orbis v0.1.0-beta.96

- Open apps side by side with edge snapping, an app picker for the other pane, and a shared divider that supports dragging and keyboard adjustment.
- Resize floating app windows from every edge and corner. Expanded windows fill the usable desktop with consistent space around the system bar and dock.
- Open app settings inside the app window and return to the running app without reloading its document. The existing settings dialog and window share the same configuration form.
- Keep app documents and drafts mounted through resizing, minimizing and viewport changes. Window motion uses transforms to avoid repeatedly laying out the embedded app during minimize and restore.
