# Orbis v0.1.0-beta.76

- Installer progress uses compact labels such as `[6/7] Backing up storage and replacing the controller`, with one count per operation.
- Live database and log growth no longer invalidate an otherwise unchanged migration review. Storage capacity, container ownership, configuration and backup integrity remain checked.
- Replacement controllers accept Docker logging defaults verified through the existing isolated image probe. Explicit logging options and other host settings remain protected.
- Failed replacements show the actual error and distinguish a completed rollback from an operation that needs recovery. Unrelated failures are no longer retried as storage-size changes.
