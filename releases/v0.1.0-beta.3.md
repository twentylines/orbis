# Orbis v0.1.0 beta 3

This remains a development preview for isolated homelab testing. It is based on Runtipi v4.10.1 and keeps the Runtipi data and application model.

## Since beta 2

- A new staging command checks a reviewed release manifest against a copied CLI installation, then writes only a generated digest-pinned core image override. It refuses to overwrite custom content.
- Migration preflight now flags external or uninspected paths for every data folder, including media and backups.
- Appearance adds Ocean and Blush presets plus Tidal and Canopy wallpapers. Earlier saved appearance files load with the Sandstone default.
- On startup, Orbis runs Runtipi's existing Docker status reconciliation before serving the app list. This corrects a stale `running` label when an inherited container is stopped.

## Current limits

No real homelab data has been migrated. Automatic Orbis installation and rollback, host package updates, and multi-server pairing are not included. Do not replace a production Runtipi installation with this preview.
