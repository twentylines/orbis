# Orbis beta48

## Compact screens

Use a coherent smaller type and spacing scale across Home, Monitor, Usage, app details, Appearance, search, release notes, login and error pages. Normal phone titles are 24–26px and section headings 16–17px. Deliberate text enlargement still reflows the layout; there is no page scaling transform.

Source checks pass 32 native route compositions, four phone width/mode groups with doubled text and 20 narrow surface samples. Retained captures include direct gutter, word wrapping and focus inspection. Those source checks are distinct from acceptance of this published image.

## Local recovery

Fail explicitly when SQLite cannot enumerate session records. After a saved password change, unsuccessful session cleanup reports a partial recovery and keeps its request for retry. Remove the session value before its index so a failed deletion remains discoverable on retry.

Real temporary SQLite connection and deletion faults reject the preceding behavior. The corrected source passes 25 recovery cases, 69 authentication tests plus seven cache cases, 656 backend tests across 54 files and seven runtime packaging checks. Backend types, bundle and strict changed-file lint pass. The user repository is mocked in the fault tests; these are not a cross-store transaction or multiprocess lock.

Beta47 separately passed actual stock adoption, retained original password/TOTP authentication, hidden-prompt CLI reset, three old-session rejections and four actual browser groups on a synthetic arm64 installation. That image does not contain this cache correction or compact UI. This release requires its own reviewed update and published-image checks.
