# Orbis 0.1.0 beta 124

- Make nearby discovery automatic on configured private HTTPS networks, with a persistent opt-out in Cluster settings. Discovery does not grant access or replace server approval.
- Open backup creation, upload and verification in guided windows, while keeping setup recovery inside the onboarding card.
- Request a restore from the destination server, approve it separately on the source, then receive and review a new encrypted backup over private HTTPS. No transfer code or prepared source export is needed.
- Encrypt new backups with the current account password when it meets backup requirements, with a separate passphrase option. Existing backups still need the password or passphrase used when they were created.
- Make Store catalogue rows more compact with consistent icon spacing and room for enlarged text, while retaining larger collection artwork.
- Group server restore in Backup & Recovery, simplify action labels, remove temporary transfer visibility controls and retain manual source addresses.
- Move customisation reset out of Import and Export and require an explicit confirmation before applying it.
- Fix transfer dialog cancellation, compact its header, and let inline pairing controls clear their fields without changing workflows.
- Keep recovery validation inside the card and show only the selected backup during setup, with one restore action.
- Protect scheduled app updates at the tracking limit without losing pending operations or changing the settings format older releases read.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
