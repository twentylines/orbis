# Orbis v0.1.0-beta.112

- CPU and memory readings now refresh every second while Home or Monitor is visible. Both views share readings, and polling pauses when the view or browser tab is hidden.
- Reduce repeated disk and network work during live refreshes. Reset CPU and network baselines after a long idle period so resumed readings cover current activity.
- Keep Home's live status updates separate from the app grid to avoid unnecessary redraws.
- Restore light and dark wallpaper shading for readable headings using a less expensive palette tint.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
