# Orbis beta 39

## Authentication details

- New authenticator enrollments use Orbis as the issuer. Existing encrypted TOTP secrets retain the same decryption and verification path.
- Origin-error guidance uses the Orbis name while keeping existing configuration fields.
- Authentication debug logging no longer records raw headers, query strings or complete redirect URLs. Session cookies and actual redirect destinations retain their existing behavior.
- Login and two-factor completion omit absent redirect fields before response validation, avoiding unnecessary validation warnings.

## Verification boundary

The source checks reproduce four failures in the preceding implementation and pass after correction. All 426 backend tests and seven frozen runtime packaging cases pass, with backend types, bundle and scoped lint. The repeated HTTP test suites keep one loopback listener without reducing request counts or bypassing throttling checks.

This is source verification. Published-image checks and copied-account TOTP/HTTPS/forward-auth browser acceptance remain required; AUTHENTICATION-QA.md records the separate fixture plan. Hades is unchanged. This preview does not complete full production/migration, theme-pack or multiple-homelab acceptance.
