# Orbis v0.1.0 beta 15

This remains a development preview based on Runtipi v4.10.1. Hades has not been changed.

## Since beta 14

- Operators can select host packages and review an APT simulation that lists every upgrade and required new dependency before installation.
- The separate Ubuntu 24.04 helper verifies exact package candidates, refuses untrusted sources and removals, and rechecks the plan immediately before applying it. Plans expire after 15 minutes.
- Approved package changes run in a separate systemd worker with a private job record and log. The worker survives a browser or Orbis core restart and never reboots the host. The Update Center shows progress, completion, failure, and reboot-request status.
- A running or unresolved package job blocks overlapping Orbis core and helper updates. The browser has no shell command field.

## Verification before publication

- The isolated Ubuntu 24.04.4 VM upgraded its beta 14 helper, simulated a one-package `base-files:arm64` transaction, then installed exactly that candidate through the systemd worker. `dpkg-query` reported `13ubuntu10.5`, `dpkg --audit` was clean, the APT candidate count fell from 110 to 109, and the beta 14 Orbis core remained healthy.
- Desktop, phone, and 320px enlarged-text fixtures showed package selection and the complete reviewed plan without page errors or horizontal overflow.
- Local checks passed 67 Python tests, 251 backend tests, 78 shared-schema tests, TypeScript checks, and the production bundle. GitHub CI and integration tests gate image publication.

## Current limits

APT package changes have no automatic rollback. A failed or interrupted dpkg transaction needs local inspection before another host operation. Repository index refresh and browser reboot controls are not yet available. The helper currently supports Ubuntu 24.04 only. Real homelab data, external mounts and named volumes, amd64 runtime, and multi-server pairing remain unverified or unimplemented. This release is for isolated testing, not a live Runtipi replacement.
