# Orbis beta66

## Installation

- Fix interactive installation when the release launcher is supplied through a pipe. Read terminal answers and write prompts through separate streams, without requiring a seekable terminal.
- Verify prompt handling against a real controlling terminal while standard input is a separate pipe.

Use this installer instead of beta65's interactive launcher. The beta65 installer stops before replacing or initializing a controller when it cannot open its terminal; its core update image is unaffected. This release retains the release-bound helper hashes, Keep/Fresh choices and recovery journals.
