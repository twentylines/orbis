# Orbis 0.8 beta 2

- Settings backups download through the browser's normal download manager without another password prompt.
- Restore has its own section and recognizes both settings exports and older full backups. Uploading stops at review before anything is restored.
- New settings exports use your account password by default. A separate backup password is optional; existing exports still use the password chosen when they were created.
- Reset and onboarding changes refresh other connected clients. Desktop preference writes from before a completed reset are rejected.
- Reset preserves saved backup retention settings.
- The startup screen keeps its background while the dashboard wallpaper loads, with a bounded wait if the wallpaper cannot load.
- Update checks continue in the background after confirmation. Progress screens say “Installing update”, and the update button says “Update”.

The complete reset redesign and Orbis Sentinel are not included. Time Machine and full app restoration remain experimental; broader rendering performance work is still in progress.
