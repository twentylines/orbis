## Upgrade preparation

- This Nightly keeps the 4.10.1 compatibility base and prepares existing Orbis installations for the 4.12 upgrade. Use the guided installer when upgrading from Orbis 0.9.1.
- Orbis Host and Sentinel can coordinate an update and carry the same update status through a service restart.

## Apps and workspace

- App windows can recover through a compatible configured address. If an app blocks embedding, Orbis offers a retry and an option to open it in a browser tab.
- The minimized app tray uses less space, and Home uses compact app tiles on phones.
- Review individual app updates from Updates and restart installed apps from the Apps menu.
- Anonymous usage and error reporting have been removed.
