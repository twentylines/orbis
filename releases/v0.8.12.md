# Orbis 0.8.12

- Improved Home editing, automatic app-card sizing, heading alignment and widget spacing.
- Preserved split-pane scroll positions and made the dock follow the pane receiving input.
- Kept app icons cached between Home, Apps and Store, and reduced redundant catalogue requests.
- Prioritized visible workspace content during startup and deferred background catalogue preparation.
- Improved dialog button contrast, app forms, Monitor history controls and guest dashboard management.
- Used the full available desktop area for 4K floating and split windows.
- Kept sign-in and sign-out text white on photographic midtones, using dark text on clearly light backgrounds.

- Added direct colour-preset choices, Monitor destinations, app management and confirmed app actions to search.
- Restored darker floating menus, sharpened the returning search box and removed routine search save messages.
- Improved pin and toolbar reordering, icon-only spacing, selected controls and Light-mode Applications depth.
- Kept the Home greeting and date white and refreshed the Sage green, Burgundy and Orange photographic wallpapers.

- Unified the shared Applications dashboard into one blurred card and tightened General preference spacing.
- Moved app creation and external-link actions into the Apps header and centred filter labels.
- Kept backup wallpaper capture aligned with the current built-in photographs while preserving historical images.

- Returned from Apps and Store details through the dock without resetting catalogue state, with smoother pane transitions.
- Added a sharper, responsive system background with colours that follow the selected theme.
