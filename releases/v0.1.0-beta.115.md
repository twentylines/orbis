# Orbis 0.1.0 beta 115

- Keep unapplied critical fixes visible when skipping releases or moving between release channels.
- Retain Stable releases and their critical update information in Nightly when GitHub's release API is unavailable.
- Enter a complete daily update time, such as `1500`, in either time field. Choose AM/PM or a 24-hour clock, with the format saved to your account.
- Keep time fields equally sized, show invalid entries beside the controls, and preserve automatic update opt-in settings when changing the time.

Runtipi remains at 4.10.1. This update does not introduce a data migration.
