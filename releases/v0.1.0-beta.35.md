# Orbis beta 35

## Preference save ordering

- Rapid theme and window changes no longer abort a preference save that has already been sent. Saves run in order; superseded queued values are skipped.
- Loading acknowledged account preferences does not send a redundant save. A failed save keeps the local choices and reports the sync failure; a later edit can recover.
- Started saves use browser keepalive. Unsaved form drafts remain separate from account preferences.
