# Orbis beta64

## Security

- Update Node.js to 22.23.4 for the [October 2026 security fixes](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases), including Brotli, DNS and TLS fixes.
- Pin the production and development base image by digest, use the same Node version in CI, and reject runtimes below the supported security minimum during image builds.

## Servers and navigation

- Pair servers into a named cluster with expiring pairing codes and signed commands. Browse individual or merged apps and updates, with separate app and Orbis update batches.
- Select servers directly through the animated rack. Open the same card selector from the topbar over a blurred background, with touch, keyboard and reduced-motion support.
- Animate the dock splitting and merging as launchers are minimized, restored or closed. Compact longer app lists on desktop while retaining ordinary pages on phones and smaller tablets.
- Show used and total RAM alongside the percentage, and place uptime beside system readings.
- Run account-specific Orbis setup even when an imported login session is still valid.

## Backups and installation tools

- Preserve subsecond timestamps and verify the archive tools used for app backups and restores.
- Review compatible controller replacements against the actual target image migration history. Retain the original controller before activation, and recover interrupted activation without rewinding newly accepted app writes.

The complete two-choice replacement installer is still in development. Existing installations must use the reviewed installation tools; this release does not establish a completed migration on a physical homelab. See [installation requirements](https://github.com/twentylines/orbis/blob/main/INSTALLATION.md).
