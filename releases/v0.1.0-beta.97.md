# Orbis v0.1.0-beta.97

- Keep multiple app windows open together, with improved snapping and layout controls. Switching sections minimizes their windows together; returning restores that section’s windows and split layout while keeping manually minimized apps tucked away.
- Window compatibility checks catch apps that block embedding before loading their frame. Choose to always open them in a new tab; tab-only apps have a title indicator and are excluded from split screen. Onboarding and Settings now offer illustrated Orbis windows / New tabs choices.
- Monitor now groups Usage, Performance, Devices and Sensors, with CPU temperature near the summary and expandable resource rankings.
- Updates has separate Orbis, Apps and System views. Compatibility checks and downloads appear in the tasks pill. Forced downgrades require an explicit risk review and red confirmation; Runtipi compatibility boundaries remain protected.
- Apps has compact filter controls, with Find an app opening global search. Apps and Store previews rearrange cards and text smoothly.
- Refreshed typography, real photographic theme wallpapers and meaningful Compact density improve readability and space across the interface.
- Release channel settings show Stable and Nightly. Stable continues to receive beta releases; Nightly remains inactive during beta.
