# Orbis 0.8.8

- Restored translucent, blurred navigation bars and menus. Panels keep their readable default fill, and saved appearance settings still take precedence.
- Simplified Store browsing and refreshed Home status, attention items, and time-of-day greetings. Network readings update every second.
- Kept split apps together when minimized, added a scroll-to-top control to the compact dock, and made Search and task activity transitions clearer.
- Moved Update Orbis beneath the version information and removed the release-channel label from the available version.
