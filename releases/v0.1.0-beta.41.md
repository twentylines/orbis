# Orbis beta 41

## Device colour mode

- Add Follow system in Appearance. Keep the selected colour preset while tracking this device's live light/dark setting.
- Apply the resolved mode to Home/Monitor instruments, desktop windows, login, guest apps, error recovery, notifications and editors. A top-bar toggle chooses a manual mode.
- Preserve the system preference through account save, reload and export/import. Device-only colour changes do not save a new account preference; manual mode removes its colour-query subscription.
- Reflow mode cards as text grows. Retain the translucent palette blur and rim-free frame for the system bar, coloured desktop headers and dock.

## Browser storage recovery

- Keep language detection and theme rendering working when JavaScript cookie or browser-storage access fails.
- Verify that the preference cache can be read back before claiming it is saved. Report temporary changes when both sync and the usable browser cache are unavailable.
- Keep guest changes local, and avoid showing an endless Saving message after a failed preference load.

## Verification boundary

Compiled-source Chrome fixtures cover 16 Appearance compositions at 1440/768/390/320px, both device modes and native/doubled text; 18 desktop/phone interaction cases; and 7 controlled storage failures. The checks inspect whole words, shared gutters, interior padding, native keyboard focus, actual painted editor/status colours, retained editor contents and restored fixture state. The negative baseline rejects the missing selector, denied-write crash, read-denial startup failure and old backend's rejected system mode.

All 430 backend tests, 15 browser dependency/storage tests, two existing editor component tests, frontend/backend types and bundles pass. Delayed/coalesced preference saving, failed-save retry and reload also pass without aborted saves. Published beta41 image, reviewed update and actual preference round-trip confirmation remain separate acceptance steps. Hades is unchanged; full theme packs, multiple homelabs and complete production/migration acceptance remain open.
