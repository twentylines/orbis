# Orbis v0.1.0 beta 12

## Since beta 11

- My Apps responds to the width of its own panel. Installed app tiles and custom action tiles become one column when the panel is narrow, even on a wider browser window.
- Start, Stop, and Restart all controls stack in that narrow panel, and long tile text wraps within its card.
- The browser layout check now exercises constrained panels, inner tile overflow, the last tile's clearance above the dock, 2× display scaling, tablet width, and a 3840px-wide workspace.

## Current limits

The host service still needs an in-place upgrade path. Real homelab data, external mounts, amd64 runtime, host OS package updates, and multi-server pairing remain unverified or unimplemented. This release is for isolated testing, not a live Runtipi replacement.
