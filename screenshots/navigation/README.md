# Navigation and app launchers

Current source build, captured on a disposable server on 21 October 2026. These are original browser captures using sample apps. The demo has a running container; the five other sample app records have no containers.

This gallery shows page navigation, desktop launchers, the split dock and phone app management. Minimized apps share the navigation dock's bottom row, and navigation contracts to icons after the fourth minimized app. Phones use ordinary pages. These captures do not demonstrate a real homelab migration.
